# smart4ai-plugins · plugins de Smart4AI para Claude

Plugins de Smart4AI listos para instalar en **Claude Cowork** y **Claude Code**. Nada se envía ni se publica sin tu aprobación.

## radar-tienda · del producto a la tienda

[`radar-tienda`](plugins/radar-tienda/) · estudio de mercado de un producto (skill de Carlos Jiménez), validación de promesas y precios, imágenes, producto en borrador en tu Shopify, anuncio para Meta revisado y tablero en vivo con recibo de costos. Nunca publica: todo queda en borrador hasta que lo apruebes. Nació en la hackatón de la Feria Effix 2026.

## Instalar

**claude.ai y Claude Cowork:** **Configuración → Personalizar → Plugins → Agregar → Agregar marketplace → Agregar desde un repositorio**, escribe `santivelezia/smart4ai-plugins`, pulsa **Sincronizar** y, en **Descubrir**, **Agregar** en `radar-tienda`.

**Claude Code:**

```
claude plugin marketplace add santivelezia/smart4ai-plugins
claude plugin install radar-tienda@smart4ai-plugins
```
